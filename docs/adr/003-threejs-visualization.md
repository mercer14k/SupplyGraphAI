# ADR 003 — Three.js views with an accessible evidence companion

Status: accepted.

Three.js replaces the recommended Cytoscape.js renderer to satisfy the requested spatial visual design. A typed API returns a bounded neighborhood; the same facts are rendered as dependency coordinates or geographic coordinates on a globe. Orbit, zoom and node selection reveal raw evidence.

Rendering is never the analytical source of truth. Full-graph computations stay in Python. Paginated evidence tables, labeled form controls, semantic dialog focus handling, and explicit error/empty states provide non-canvas paths through the workflow. Unsupported WebGL produces a table-oriented fallback. The geographic view is a network-coordinate visualization, not a map of real supplier operations.
