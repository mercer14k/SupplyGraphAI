# Community code of conduct

Contributors and maintainers commit to a respectful, inclusive environment. Welcome different experience levels, credit others' work, give specific technical feedback, and assume good intent while taking reported harm seriously.

Harassment, discrimination, threats, doxxing, sexualized attention, and sustained disruption are unacceptable. Do not post private information without permission. The same expectations apply to issues, reviews, discussions and project events.

Maintainers may edit or remove inappropriate contributions, request changes, temporarily restrict participation, or ban repeated or severe offenders. Enforcement should be proportionate, documented privately where appropriate, and allow affected people to clarify or appeal through an available private project channel.

Report concerns privately using the published repository's available reporting channels. If no private channel exists, request one without publishing personal details. Do not retaliate against good-faith reports.
